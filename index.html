Helm Charts

Helm charts for Kubernetes, published as a Helm repository

Quick start

helm repo add quyendv https://quyendv.github.io/helm-charts helm repo update helm search repo quyendv

Charts

generic-app

A generic chart for deploying an application: Deployment, StatefulSet or DaemonSet, with Service, Ingress, Gateway API, ExternalSecret and more.

Documentation

platform-backup

A scheduled backup of one PostgreSQL, MongoDB, Redis or SQLite store to S3-compatible storage.
